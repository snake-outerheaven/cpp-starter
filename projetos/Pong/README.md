# Pong

Um simples clone do jogo Pong.




## Objetivo

Fazer um clone simples do jogo clássico Pong, com a adição de elementos de jogos pinball, com contador de pontos
nome do jogador, nível de dificuldade, e mais uns extras.




## Estrutura do projeto

- `bin/`: aqui vai ter o binário pronto do jogo, podendo ser executado diretamente ou com make run.
- `build/`: arquivos objetos gerado durante a compilação estarão aqui.
- `src/`: arquivos de código fonte estarão aqui.
- `include`: cabeçalhos de bibliotecas criadas para o jogo estarão aqui.
- `lib/`: Implementações de bibliotecas criadas para o jogo estarão aqui.
- `Makefile`: script de compilação, execução do jogo e limpeza de diretórios


## Como compilar:

Em um sistema com make disponível, além do simples make que faz a compilação, haverão dois comandos específicos.

**1º**

```
  make run
```
*Este executará o passo de compilação e cuidará da execução do binário gerado.*

**2º**

```
  make clean
```
*Este fará a limpeza do ambiente do projeto, removendo as pastas bin/ e build/, deixando apenas as partes de código fonte.*
